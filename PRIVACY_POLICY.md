# Privacy Policy for GRD Sentinel Network Auditor
**Entity:** Golden Ratio Dynamics  
**Effective Date:** November 15, 2026  

### 1. Data Collection & Processing
GRD Sentinel Network Auditor operates on a strictly local diagnostic standard. The application measures real-time network parameters including:
- Latency (HTTP RTT, Jitter, Bufferbloat)
- DNS Resolution Speed
- Throughput and Goodput
- Wi-Fi RSSI, Band, and Cipher Suite
- Cellular Radio Metrics (RSRP, Frequency Bands)

### 2. Zero-Entropy Data Retention Standard
- **No Remote Telemetry:** All network calculations, latency checks, and cipher audits are processed entirely on the local device.
- **No Third-Party Brokers:** We do not sell, share, transmit, or monetize any diagnostic telemetry or personal identifiers.
- **Local SHA-256 Ledger:** Any diagnostic report hashes generated within the application remain in local storage under the user's explicit control.

### 3. Permissions
The application requests network and telephony state permissions solely to determine local radio frequency signal strengths and interface configurations. No call logs, personal identity documents, or communication contents are accessed or stored.
